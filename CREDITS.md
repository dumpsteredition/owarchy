# Credits and third-party notices

OWARCHY is built for the Omarchy plugin interface and runs in [Quickshell](https://github.com/quickshell-mirror/quickshell). It also relies on these separately installed projects and libraries:

- [Omarchy](https://github.com/omacom/omarchy)
- [`ttfx`](https://github.com/omacom-io/ttfx), Omacom’s Rust port of [TerminalTextEffects](https://github.com/ChrisBuilds/terminaltexteffects), the original project
- [GTK 3](https://www.gtk.org/) and [PyGObject](https://pygobject.gnome.org/)
- [VTE](https://gitlab.gnome.org/GNOME/vte) 2.91 and [gtk-layer-shell](https://github.com/wmww/gtk-layer-shell)
- [Wayland](https://wayland.freedesktop.org/) client libraries
- JetBrainsMono Nerd Font or another installed font configuration that can render the selected effects

The repository’s proposed MIT license applies to OWARCHY-authored code only. It does not relicense these dependencies or other upstream projects; each retains its own license and trademarks. Check the linked upstream project or distribution package for its current terms.
